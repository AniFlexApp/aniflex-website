# AniFlex — Marketing Landing Page

Static single-page marketing site for the AniFlex anime-fitness RPG mobile app.

- Plain HTML/CSS/JS — no build step, no backend. Host anywhere static (Netlify free tier works as-is).
- "Forge Your Hero" uses the app's real stat-roll mechanics (5 dice of 1–10, reroll under 20) and the real 16-kit base-class derivation logic.
- Avatar parts and screenshots are compressed WebP copies of the app's assets.

## Local preview
Just open `index.html` in a browser.
